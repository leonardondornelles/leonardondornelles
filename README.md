### 👨‍💻 About Me

I'm a Computer Science student at **PUCRS** (Porto Alegre, Brazil) and a **Backend Intern at Nelogica**, where I work on the backend of an electronic trading platform using **C#/.NET, Delphi and SQL Server**, covering brokerage integrations and account risk management.

Previously, I was an **Undergraduate Research Fellow at DaVInt Lab (PUCRS)**, researching social media bot detection with a focus on data quality for machine learning: I built data collection pipelines with the YouTube Data API (100,000+ comments) and validation/annotation pipelines to produce a labeled dataset for model training.

I enjoy building reliable, well-structured backend systems, from protocol design and backward-compatible migrations to tracing production issues end to end.

### 🚀 Featured Projects

**[SaasOOH Platform](#)** · Java 21, Spring Boot, Spring Security, Next.js, TypeScript, PostgreSQL
Full-stack multi-tenant SaaS for Out-of-Home advertising management, featuring stateless JWT authentication, role-based access control (RBAC), tenant-level data isolation, and business dashboards for MRR/ARR, regional occupancy, sales pipeline and contracts.

**[Air Network Route Optimization](#)** · Java 17, Python, Folium
